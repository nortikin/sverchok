Offset Line lite
================

Functionality
-------------

It is most simple offset case.

Inputs
------

This node has the following inputs:


- **Vers** - Vertices of objects

- **Edgs** - Edges of objects


Options
-------

- **Offset plane** - Plane on wich lines will be offseted:
  XY: Z is up
  XZ: Y is up
  YZ: X is up

- **Offset** - Subj


Outputs
-------

This node has the following outputs:

- **Vers**
- **Edgs**


Examples of usage
-----------------

It is so simple, that no need to be exampled
